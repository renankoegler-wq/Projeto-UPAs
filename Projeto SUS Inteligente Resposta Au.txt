Projeto SUS Inteligente: Resposta Autônoma de Emergência
Este projeto consiste em uma plataforma de gerenciamento centralizado para o Sistema Único de Saúde, o projeto tem inteção de diminuir as filas das UPAs ao otimizar as filas considerando o resto das UPAs da cidade do usuário. O ecossistema unifica inteligência artificial, dados clínicos e geoprocessamento em uma única interface operacional.

Requisitos Funcionais 

1_ o sistema deve calcular quantos pacientes tem na UPA atual
2_o sistema deve ser integrado ao google maps
3_o sistema deve ter integração com uma IA
4_o sistema precisa ter login e cadastro
5_o sistema precisa ter integração com o gov
6_o sistema precisa fazer calculos para otimizar rotas utilizando o google maps
7_o sistema deve ser alinhado ao sistema do recepcionista
8_o sistema deve avisar a outra UPA que o paciente POSSIVELMENTE está vindo
9_o sistema deve classificar o problema do usuário para dar niveis de risco
10_o sistema deve calcular o tempo de espera com base em seu risco, sua localização atual e o tempo da fila.

Regras De Negócios

1_O sistema tem que ser justo
2_O sistema tem que ser eficaz
3_O sistema deve aumentar a estimativa de vida, ou melhorar o respeito do povo pelo sistema de UPAs
4_O sistema deve ser acessivel
5_O sistema tem que ser simples e compreensivel

Persona

Nome:Sérgio Rodrigo da Silva
idade:53 anos
Problema:está com uma espera muito grande em sua UPA

Jornada Do Usuário

1_ Tem um problema físico ou mental que necessite de ajuda médica que é fornecida pelo SUS
2_ Vai a UPA mais proxima de seu lugar atual
3_ Chega no lugar e vê uma fila enorme, sentindo insatisfação visto que talvez esteja em estado de urgencia
4_ Sente a necessidade de ir para outra UPA
5_ Abre o site
6_ Se cadastra ou faz o login
7_ Gera uma consulta do sistema considerando sua cidade, UPA atual e tempo de espera previsto considerando o quanto de pessoas estão no lugar
8_ Adquire o resultado, vendo se compensa ou não mudar de UPA
9_ sobre o julgamento do usuário, ele vai até uma UPA onde economize certo tempo e dinheiro
10_ Problema do usuário satisfeito
